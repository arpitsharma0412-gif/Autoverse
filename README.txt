AUTOVERSE — HTML + CSS starter website

FILES
- index.html          Home
- buy.html            Browse car listings
- car-details.html    Example vehicle details
- sell.html           Seller listing form (visual demo)
- rent.html           Rental listings and date fields (visual demo)
- about.html          About AutoVerse
- contact.html        Contact form (visual demo)
- style.css           Shared responsive styles and animations

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in a browser.
3. Use the navigation to move between pages.

NOTES
- Built with HTML and CSS only; no JavaScript or framework.
- Forms and search controls are visual front-end demonstrations. They do not submit, filter, book, upload or save data.
- Replace sample listings, prices, contact details and image URLs before publishing.
- Images are loaded from Unsplash, and fonts from Google Fonts, so those assets need an internet connection.
